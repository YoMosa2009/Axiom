# Security policy

Axiom runs AI models that can read files, run commands and control the desktop (Agent Access
and @ComputerUse), and it stores API keys on your computer. Security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately instead:

- [Report a vulnerability](https://github.com/YoMosa2009/Axiom/security/advisories/new) on GitHub, or
- email **malxshrouds@gmail.com** with "Security" in the subject.

Include what you found, how to reproduce it, and the Axiom version. You'll get a reply as soon
as possible, and a fix will be released before the details are made public.

## Supported versions

Only the latest release receives fixes. Axiom updates itself in-app; please update before
reporting.

## Verifying a download

Official builds are published only on this repository's
[Releases page](https://github.com/YoMosa2009/Axiom/releases). Axiom isn't code-signed yet, so
don't trust copies from anywhere else.
